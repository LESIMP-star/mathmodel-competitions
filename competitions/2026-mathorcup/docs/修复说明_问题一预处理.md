## 2. 改了什么代码

### 2.1 `q1.py`：预处理移进内层折（两处）

**问题**：内层 5 折切分之前，就用整个外层训练集（200 个样本）算好了中位数与标准差。内层验证折的特征信息因此进了参数估计，内层选型不再干净。外层测试折没参与，所以**不是外层泄漏**，不能说「性能一定虚高」。

**改法**（`nested_cv_one`，`q1.py:228` 起）：

```
改前：med/sd 用整个外层训练集算 → prep(A) → kf_in.split(A) → 内层循环
改后：kf_in.split(Xtr_raw) → 每个内层折内部：
        med_i, sd_i = _fit_prep(Xtr_raw[itr])     # 只用内层训练折
        A_i = _apply_prep(Xtr_raw[itr], med_i, sd_i)
        B_i = _apply_prep(Xtr_raw[ite], med_i, sd_i)
      内层选完模型后，再在整个外层训练折上重估一次：
        med, sd = _fit_prep(Xtr_raw)
        B = _apply_prep(Xte_raw, med, sd)
```

新增两个辅助函数 `_fit_prep()` / `_apply_prep()`，把「估参数」和「用参数」分开，谁估的谁用一目了然。

**第二处**：`sd` 改为在**用中位数填补之后**的矩阵上算——

```
改前：sd = np.nanstd(np.nan_to_num(Xtr_raw, nan=0.0), axis=0)   # 缺失当 0
改后：filled = np.where(np.isfinite(Mtr), Mtr, med); sd = filled.std(axis=0)
```

改前那行会把缺失处当真实 0，与随后实际的填补值不一致，列标准差被系统性放大。

### 2.2 `q2.py`：只改注释，不改逻辑

数值一个都没变，所以**不需要重跑**。改了三处注释：

- 模块头 `①`：覆盖度 226/226 → 231（Others 由 20 改 25，含 5 个派生总量），并写明「逐列而非整组」的真实理由（整组只给 7 个族级数，拆到单列必须人为摊派，而摊派方式决定排名）
- 模块头 `③` 与 `fdr_threshold` 的 docstring：写明 $q_{\rm sel}$ 与 $q$ 的区别、0.5022 只是操作性阈值、不构成 0.05 水平的 FDR 控制、按 $q_{\rm sel}=10$ 原义应得 0.7165
- 函数名保留 `fdr_threshold`，避免下游引用断掉；语义以 docstring 为准

### 2.3 没改的

`q3.py`、`q2_graph.py`、`nsga2.py`、`figures.py` 全部未动。**Q3 不依赖 Q1**（`q3.py` 只读 `附件/` 与 `q2_top3.csv`），所以 Q3 的 Pareto、迁移、灵敏度数字一个字都不用改。

### 5.5 问题二的措辞（对应第 1 节 #1/#2/#3）

不改数值，改四处说法：

1. **7.2 节标题**：「分组置换重要性模型」→「置换重要性与入选频率模型」
2. **7.2 节的公式与解释**：现在是
   $$\pi_g=\frac1B\sum_b\left(\mathrm{MSE}_{\text{打乱族 }g}-\mathrm{MSE}_{\text{原样}}\right),\quad g=1..7$$
   建议改为
   $$\pi_j=\frac1B\sum_{b=1}^{B}\mathbf{1}\left[j\in\mathrm{Top10}\left(\Delta^{(b)}\right)\right],\quad B=200$$
