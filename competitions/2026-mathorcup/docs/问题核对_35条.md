### P0-2　Q3 的 f3 定义与代码不符（报告第 19 条）

**论文式(15)**：$f_3(x)=\sum_j |x_j-x_j^0|$

**代码 `q3.py:490`**：

```python
f3 = float(gamma * np.sum(y) + lam * np.sum(arr['wj'] * (dp + dn)))
```

`gamma=1.0`、`lam=0.1`、`wj=1/(ub-lb)`。以 P1 验证：改动 7 个化合物 → `gamma*7=7`，归一化幅度和 ≈4.51，`f3 = 7 + 0.1×4.51 = 7.451`，正是表 12 的 P1。

**结论**：f3 主体是**改动个数**，不是改动幅度；表 12 的「改动化合物数」列与 f3 第一项重复。**报告完全正确。**

### P0-3　ε3 约束与报告的 f3 不是同一把尺子（报告第 20 条）

**约束**（`q3.py:383-387`）用未加权 `lam`：

```python
add(r, i_dp + j, lam); add(r, i_dn + j, lam)
```

**指标**（`:490`）用加权 `lam * wj`。所以 `q3_pareto.csv` 里 P1 的 `e_f3=10.2245` 与 `f3=7.4510` 不相等。**前沿的 ε 网格和表 12 的 f3 口径不同，前沿不可复现。**报告正确。

### P1-2　标签是品评员 z-score，不是「未感知」（报告第 8 条）

**原论文 Methods 原文**（我查了 `beer.pdf`）：

> Scores were scaled by standard deviation and mean-centered per taster. Values are represented as **z-scores**.
>
> Panelists were trained to identify and score 50 different attributes, using a **7-point scale** to rate attributes' intensity.

**结论**：附件4 是「16 位品评员按 7 点量表打分 → 按品评员 z-score → 按啤酒平均」。
- 负值 = 低于该品评员平均，不是「未感知」；
- 列最小值 = z 空间左尾，不是「感官 0 分」；
- 我们定义的 φ_s（与列最小值相距 ≤0.15 的样本占比）是**左尾占比**，不是未感知比例；
- 两段式分类头的目标 `y > min(y)+0.15` 是「高于左尾窗」，不是「是否感知」。

**佐证**：我们自己的结果是两段式组均值 0.1823 < 非两段式组 0.2310，说明「先判有无」没带来增益。报告正确。

**处置**：标签描述改为「按品评员 z-score 后再平均的连续强度」；φ_s 改名「左尾占比」；两段式改为「尾部敏感性模型」并明说未提升精度。
