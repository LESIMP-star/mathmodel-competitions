## 二、A 类：必改的四处

### A1. 图注里的"分栏说明"要移进子图标题

现在有多张双栏图，`\caption` 里写着"左图为…右图为…"。这种写法有两个问题：
正文已经讲过一遍，图注再讲一遍是重复；而且评审看 PDF 时图注和正文不在一页，找起来费劲。

改成：每个子图上方一行短标题（`ax.set_title('(a) 真实缺失列')`），图注只留一句总述。

涉及：

| 图 | 现在 caption 里的分栏说明 |
|---|---|
| `fig_q0_missing` | "左图为真实缺失列及其缺失率，右图为检出限地板值列" |
| `fig_q0_box_before_after` | "左图为原始浓度对称对数轴，右图为 $\log_{10}$" |
| `fig_q1_reg_fit` | 四个项的对照 |
| `fig_q1_residual` | "残差散点、Q--Q 图、分布直方图与残差序列" |
| `fig_q2_graph` | "左图为 Louvain 模块度与度保持零分布，右图为三种聚类方式的模块内外 $\|\rho\|$ 对比" |
| `fig_q3_front` | "双投影对比" |

**注意**：子图标题只写 `(a)`/`(b)` + 三五个字，**不要加括号补充说明**（这条之前已经踩过，见 C 类）。

### A2. 两张图排到一行

现在 `fig_q3_surrogate_cv` 与 `fig_q3_surrogate_err` 各占半页，加起来将近一页。
这两个图都是"质量诊断"，信息密度低，应该并成一张双子图：

```python
fig, axes = plt.subplots(1, 2, figsize=(11, 4.2))
# (a) 逐项交叉验证 R²   (b) 误差与标准差之比
```

同理 `fig_q2_convergence` 与 `fig_q2_jaccard` 也是一对，可以并。

省下来的版面给 `fig_q2_pi_heatmap`（那张矩阵图现在偏挤）。

### A3. 表格要占满版心

现在 `tabular*` + `\extracolsep{\fill}` 已经占满了，但**行内文字间距偏小**，看起来密。
改 `\tabcolsep`：

- 数字列之间：现在是默认值，加到 `6pt`
- 表头与表体之间：`\arraystretch{1.15}`
- 三线表中间那条线：`\cmidrule` 不要，保持纯 `\toprule/\midrule/\bottomrule`

涉及表：表 5（模型对比）、表 6（逐项结果）、表 10（Top-3）、表 12（Pareto）、表 14（缺陷物）、表 15（灵敏度）。

**表 12 特别注意**：现在是 7 行（原来 5 行），加了两个点。行高要控制住，别让表跨页。

### A4. 长化合物名换行

`\texttt{X2.methyltetrahydrofuran.3.one}` 这种名字在正文里会撑出 overfull。
现在是用 `\allowbreak` 手动断的，但这只解决了一处。凡是表格/正文里出现长化合物名，都要：

```latex
\texttt{X2.methyl\allowbreak tetrahydrofuran}\allowbreak\texttt{.3.one}
```

或者更省事：定义个宏

```latex
\newcommand{\chem}[1]{\texttt{\seqsplit{#1}}}
```

## 三、B 类：建议改的六处

### B1. 配色统一

现在 21 张图里，Q1 用蓝绿系、Q2 用紫系、Q3 用青系，但同类含义的颜色不统一。
建议定三色语义，全文一致：

- **蓝 `#2E5E8C`**：真实值 / 基准
- **橙 `#D97B4F`**：模型预测 / 优化解
- **灰 `#8C8C8C`**：参考线 / 零分布

定义在 `figures.py` 顶部一次，全部图引用，不要各处硬编码。

### B2. `fig_q1_r2_forest` 的 50 个点太挤

现在是 50 行森林图，字号压到 7pt 才能塞下。两种改法：

1. 只画 $R^2$ 最高的 20 项 + 最低的 10 项，中间用省略号
2. 保留 50 项但改横向布局（项名在左、点在中、数值在右）

推荐第 2 种，信息不丢。

### B3. `fig_q2_pi_heatmap` 的 colorbar 刻度

$\pi$ 的取值在 0 到 0.72 之间，但 95% 的格子小于 0.1。
线性 colorbar 会让大部分格子看起来一样白。改用 `TwoSlopeNorm` 或直接把 colorbar 设成对数刻度。

### B4. `fig_q3_radar` 的轴标签

现在 10 个轴标签有 2 个重叠（`aftertaste` 和 `body` 挨太近）。
把 `ax.set_rlabel_position` 调一下，或者把标签按角度分两圈放。

### B5. `fig_q3_waterfall` 的累积线

瀑布图现在只有柱，没有累积曲线，看不出"哪一步贡献了多少"。
加一条累计折线（右侧 y 轴），末端标总数。

### B6. `fig_flow` 的字号

全文技术路线图的框内文字是 7 层 6.8pt，缩到正文宽度（0.95\textwidth）后约 5.5pt，偏小。
要么把图放大到 `width=\textwidth` 且留白收紧，要么减少每个框的字数（一行不超过 8 字）。

## 四、C 类：已经踩过的坑，不要再改回去

这四条是之前反复调出来的，改回去评审会直接看出来：

1. **图内不要加总标题**。`figures.py` 依赖 `code/_notitle.py` 屏蔽 matplotlib 的默认标题，**这个文件不能删**，`import` 也不能动。
2. **子图标题只写 `(a)`/`(b)`，不加括号说明**。"(a) 真实缺失列"可以，"(a) 真实缺失列（含 LOD）"不行。
3. **参考线用图例，不要在图上写字**。`fig_q1_r2_dist` 的三条竖线原来是在图内旋转 90° 写"中位数 0.1469"，遮挡严重，已改成 `Line2D` 图例。
4. **A1 附录的分级大表是 25 列 × 2 张**。不要试图合回一张 50 列的表——试过，`\tiny` + `\tabcolsep 0.8pt` 仍然超宽 325pt。
