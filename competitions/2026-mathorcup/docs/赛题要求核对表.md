### 问题 2：化合物–风味分析

> 利用 2.csv 的化合物相关数据构建化合物共表达图，结合 1.csv 特征，给出每个感官维度的 Top-3 关键因素化合物，并进行稳定性与化学合理性论证。注：稳定性可通过 bootstrap 重采样下 Top-3 入选频率、或不同建模方法间 Top-3 的 Jaccard 系数来量化。

| 子要求 | 状态 | 证据 |
|---|---|---|
| 用 2.csv 构建共表达图 | ✓ | `code/q2_graph.py`；231 节点图，Louvain 模块度 Q 与度保持零分布对照，三种聚类方式的模块内外 $\|\rho\|$ 对比（图 `fig_q2_graph`） |
| 结合 1.csv 特征 | ✓ | 用 231 维化学谱预测 50 个感官项，置换重要性在预测性能上定义 |
| 每个感官维度 Top-3 | ✓ | 50×3 = 150 条，表 10 + `results/q2_top3.csv` |
| 稳定性：bootstrap 入选频率 | ✓ | 200 次自助重采样，频率 $\pi_j$；收敛曲线图 `fig_q2_convergence` |
| 稳定性：跨模型 Jaccard | ✓ | 三模型族（LightGBM / ExtraTrees / 岭回归）两两 Jaccard，图 `fig_q2_jaccard`；题面说"或"，本文两条都做了 |
| 化学合理性论证 | ✓ | 浓度/阈值比（OAV）分档：A 19 / B 8 / C 40 / N 83，`fig_q2_oav` + 表 11；同时满足 $\pi\ge0.5022$ 且 A 档的 **10 条** |
| 阈值选取有据 | ✓ | $\pi_{\text{thr}}=0.5022=(1+1/231)/2$；论文明确说明这是稳定性准入阈值，**不是** 0.05 水平的 FDR 控制 |

**说明**：方法名为"逐列置换重要性"而非"分组置换"——整组置换只产出 7 个族级数值，要落到单化合物排名必须人为摊派比例，摊派方式本身决定排名，论文已如实改为逐列并写明代价（同族顶替低估重要性）。
